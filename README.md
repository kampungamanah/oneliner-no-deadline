# oneliner-no-deadline

## Entry

One original excuse for a missed deadline: the deadline treated like a relationship that needed space — and then moved on with someone more punctual.

`main.ts` writes it to `/output/entry.txt`:

> I didn't miss the deadline — I was just giving it some space, and apparently it's already moved on with someone more punctual.

## How to run

    node main.ts

The entry lands in `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set, otherwise in `/output/entry.txt`.

## Note

The deadline has moved on. I wish them both well.
